# VPN Sales Bot 🤖

ربات تلگرام برای فروش و مدیریت اشتراک‌ها با رابط کاربری فارسی. این مخزن پروژه را به‌عنوان نمونه‌کار معرفی می‌کند و ویدئوی نمایشی آن را در اختیار بازدیدکنندگان قرار می‌دهد.

## معرفی

هدف پروژه، یکپارچه‌کردن بخش‌هایی از فرایند فروش و مدیریت اشتراک در محیط تلگرام است؛ از تعامل با کاربران تا ابزارهای مدیریتی و اطلاع‌رسانی.

## امکانات معرفی‌شده

- خرید و تمدید اشتراک
- ارسال رسید و پیگیری پرداخت
- تحویل پیکربندی پس از تکمیل فرایند خرید
- مدیریت اشتراک و تاریخ انقضا
- کدهای تخفیف و دعوت دوستان
- تیکت پشتیبانی
- پنل مدیریت و آمار
- ارسال پیام همگانی
- یادآوری تمدید
- پشتیبان‌گیری از پایگاه داده
- ثبت فعالیت‌های مدیریتی
- رابط فارسی و پشتیبانی از تاریخ شمسی

## فناوری‌ها

| بخش | فناوری |
|---|---|
| زبان اصلی | Python |
| Telegram Bot | aiogram |
| API / Backend | FastAPI |
| ORM | SQLAlchemy |
| پایگاه داده | SQLite |

## وضعیت سورس و اجرا

**کد منبع عمومی نیست.** این مخزن برای معرفی قابلیت‌ها و ارائه‌ی دمو نگهداری می‌شود؛ فایل‌های کد و تنظیمات اجرایی در آن منتشر نشده‌اند. بنابراین راهنمای نصب یا اجرای محلی ارائه نمی‌شود.

برای حفظ امنیت، توکن ربات، کلیدهای API، اطلاعات کاربران، پیکربندی سرور و نسخه‌های پشتیبان پایگاه داده را در مخزن عمومی قرار ندهید.
